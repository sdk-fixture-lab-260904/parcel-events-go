# github.com/sdk-fixture-lab-260904/parcel-events-go

Type-safe Go SDK — generated by the [Doctorine](https://doctorine.dev) SDK Foundry. Runtime dependencies: the Go standard library ONLY (the HTTP kernel is vendored under `kernel/`; the generated `go.mod` has no require block).

## Install

```sh
go get github.com/sdk-fixture-lab-260904/parcel-events-go
```

## Quickstart

```go
ctx := context.Background()
client := parcelevents.NewClient(parcelevents.WithAPIKey("my-api-key"))

var body parcelevents.CreateLabelRequest
if err := json.Unmarshal([]byte("{\"format\":\"pdf\",\"page_size\":\"four_by_six\",\"shipment_id\":\"shp_00000000000000000001\"}"), &body); err != nil {
	panic(err)
}
result, err := client.Labels.Create(ctx, body, parcelevents.LabelsCreateParams{IdempotencyKey: "123e4567-e89b-12d3-a456-426614174000"})
if err != nil {
	panic(err)
}
fmt.Println(result)
```

## Authentication

- `WithAPIKey` — API key sent as header `Parcel-API-Key` — falls back to the `PARCEL_EVENTS_API_KEY` environment variable.
- `WithBearerToken` — Bearer token — falls back to the `PARCEL_EVENTS_BEARER_TOKEN` environment variable.

```go
client := parcelevents.NewClient(parcelevents.WithAPIKey("my-api-key"))
```

## Pagination

List methods return `*kernel.Page[T]` — the Pager walks EVERY page transparently (or range over `pager.All(ctx)` on Go 1.23+):

```go
page, err := client.Pickups.List(ctx, parcelevents.PickupsListParams{})
if err != nil {
	panic(err)
}
for item, err := range page.Pager().All(ctx) {
	if err != nil {
		panic(err)
	}
	fmt.Println(item)
}
// or page-by-page: page.Items(), page.HasNextPage(), page.GetNextPage(ctx)
```

## Errors

Non-2xx responses surface as typed errors: reach the response with `errors.As`, match status families with `errors.Is`:

```go
_, err := client.… // any call
var typed *parcelevents.AuthenticationError
if errors.As(err, &typed) {
	fmt.Println(typed.Status, typed.RequestID)
}
var apiErr *parcelevents.APIError
if errors.As(err, &apiErr) {
	fmt.Println(apiErr.Status, apiErr.Body)
}
if errors.Is(err, parcelevents.ErrRateLimit) {
	// backoff
}
```

## Retries & timeouts

Retries are on by default (max 3, exponential backoff from 250 ms, honoring `Retry-After`). Configure per client:

```go
policy := kernel.DefaultRetryPolicy()
policy.MaxRetries = 5
client := parcelevents.NewClient(parcelevents.WithRetryPolicy(policy), parcelevents.WithTimeout(30*time.Second))
```
